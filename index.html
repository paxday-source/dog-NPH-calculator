0.3cc U100 주사기

U100은 1 mL당 100 U인 눈금 규격입니다. 0.3cc 주사기의 최대 숫자 눈금은 30입니다.

계산 위치 확대

확대 화면의 숫자는 U100 주사기 숫자 눈금입니다.

위 그림은 선택한 최소 눈금을 반영한 주사기 개념도입니다. 실제 크기와 다르며 빨간 선은 계산한 U100 숫자 눈금 위치입니다. 실제 주사기로 계량할 때는 고무마개의 바늘 쪽 가장자리를 기준으로 확인하세요. 그림은 계량 도구가 아닙니다. 0.5 U 최소 눈금 제품은 인접한 정수 눈금 사이에 표시선이 하나 더 있습니다.

주사기 눈금 확인

0.3cc = 0.3 mL이며 U100 주사기의 최대 숫자 눈금은 30입니다. NPH U100의 실제 U와 U100 주사기 숫자 눈금은 같습니다.

계산 원리 보기

실제 총 U = 체중 × 목표 U/kg
부피 mL = 실제 총 U ÷ 100
U100 숫자 눈금 = 실제 총 U
총 칸 수 = U100 숫자 눈금 ÷ 선택한 최소 눈금
kg당 칸 수 = 목표 U/kg ÷ 선택한 최소 눈금

투약 전 확인

NPH U100 바이알과 U100 주사기를 사용하는 계산기입니다. 다른 농도나 다른 종류의 인슐린에는 적용하지 마세요.

1회 용량과 하루 총량을 구분하세요. 용량 및 투여 횟수는 수의사의 처방을 따르세요. 다른 인슐린에서 전환할 때 기존 용량을 자동으로 적용하는 계산기가 아닙니다.

현탁액의 혼합 방법은 해당 제품 설명서를 따르세요. 펜 제품에서 주사기로 뽑는 방식에는 이 계산기를 사용하지 마세요.
